# Frontend Components

This Skill provides Claude Code with specific guidance on how to adhere to coding standards as they relate to frontend components.

## When to use this skill

Use this skill when:

1. Creating reusable components for displaying stock quote information
2. Building portfolio management components for adding/removing stocks
3. Designing chart components for visualizing price trends and performance
4. Implementing form components for stock search and filtering
5. Creating table components for displaying portfolio holdings and market data
6. Building notification/alert components for price alerts and recommendations
7. Designing layout components that organize API documentation or web dashboards
8. Creating modal components for confirmations in portfolio operations
