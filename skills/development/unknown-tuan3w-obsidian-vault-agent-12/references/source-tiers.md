# Source Credibility Tiers

When assessing sources, assign one of these tiers. The tier informs how much weight a claim gets in synthesis — a single L1 source can anchor a finding, while L4 claims need corroboration.

## L1 — Primary / Authoritative
- Peer-reviewed papers (Nature, Science, NeurIPS, ICML, ACL, ICLR)
- Official documentation (API docs, specs, RFCs, whitepapers from the org that built it)
- Primary data (government statistics, SEC filings, census data, benchmark results from the team that ran them)
- Author's own description of their work (Anthropic's blog about their model, a researcher's post about their paper)

## L2 — Established Expert
- Technical blogs from known practitioners (Karpathy, Lilian Weng, Colah, Simon Willison)
- Well-researched long-form journalism (The Information, Stratechery, Works in Progress)
- Preprints with institutional backing (arXiv from major labs like Google, Meta, Anthropic, OpenAI)
- Established reference sites (Wikipedia for basic facts, MDN for web standards)
- Conference talks by recognized experts

## L3 — Curated Media
- Tech news (TechCrunch, The Verge, Ars Technica, Wired)
- Podcasts and interview transcripts
- Company blog posts — treat promotional claims with skepticism, especially about own products
- Books by credible authors (useful for frameworks and synthesis, less for breaking facts)

## L4 — Community / Informal
- Reddit discussions, Hacker News threads, Twitter/X posts
- GitHub READMEs, issues, discussions
- Personal blogs without established track record
- Forum posts, Discord messages, Stack Overflow answers

## How to Use Tiers

- Every factual claim ideally has L1 or L2 backing
- L3-L4 sources are valuable for: practitioner experience, sentiment, counter-arguments, practical gotchas, "what actually works in production"
- When L3-L4 is the only source for a claim, flag it as "community consensus" or "anecdotal"
- When sources from different tiers contradict, the tier difference is relevant context — but a well-argued L4 source with data can outweigh a vague L2 opinion
- SEO content farms (sites that exist to rank, not to inform) should be skipped entirely — you'll recognize them by thin content, excessive ads, and generic phrasing that adds nothing
