## 차트 생성 도구

QuickChart 무료 API를 사용하여 Chart.js 기반 차트 이미지 URL을 생성합니다.

### 사용 가능한 도구

- **quickchart_generate**: 데이터로 차트 이미지 URL 생성 (bar, line, pie, doughnut 등)

### 사용법

- 분석 결과를 시각화할 때 사용
- 생성된 URL은 이미지로 바로 사용 가능
