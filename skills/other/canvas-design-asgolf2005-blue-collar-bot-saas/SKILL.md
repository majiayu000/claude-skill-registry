# Canvas Design

## Overview

This skill creates sophisticated visual art through a two-phase design process. Use when creating posters, graphics, professional imagery, or any static visual design that requires high aesthetic quality.

## Design Process

### Phase 1: Establish Design Philosophy

Before creating any visual, articulate a clear aesthetic movement and design philosophy (4-6 paragraphs) that covers:

- **Visual Language**: Define the core aesthetic approach (minimalist, brutalist, organic, retro-futuristic, luxury, etc.)
- **Form & Composition**: How shapes, space, and balance will be used
- **Color Theory**: Palette choices and color relationships
- **Typography**: Font choices and how text integrates as a design element
- **Conceptual Depth**: Subtle references or themes embedded in the work

The philosophy should emphasize that the final work appears meticulously crafted by an expert at the top of their field, suggesting countless hours of painstaking attention to detail.

### Phase 2: Create Visual Artifact

Execute the design philosophy to create a PDF or PNG with these principles:

1. **Visual Priority Over Text**
   - Information lives in design, not paragraphs
   - Use minimal text as visual accent, not explanation
   - Typography is an integral design element

2. **Museum-Quality Execution**
   - Treat every element as if it required countless hours of expert labor
   - Flawless formatting with proper margins and breathing room
   - Nothing falls off the page - all elements within canvas boundaries

3. **Sophisticated Composition**
   - Use repeating patterns and perfect shapes
   - Maintain professional spacing and alignment
   - Create visual hierarchy through design, not decoration

4. **Conceptual Sophistication**
   - Embed subtle, niche references (like a jazz musician quoting another song)
   - Create work that rewards familiarity but works aesthetically on its own
   - Avoid literal representation - embrace sophisticated visual communication

## Output Specifications

- **Format**: Single-page PDF or PNG (unless multiple pages requested)
- **Quality**: Magazine or museum exhibition quality
- **Margins**: Proper spacing, nothing cut off
- **Text**: Minimal and essential-only
- **Style**: Varies based on brief, but always expertly crafted

## When to Use This Skill

- Creating professional graphics to replace placeholder images
- Designing posters, flyers, or promotional materials
- Building brand assets (backgrounds, hero images, etc.)
- Creating visual art for presentations or websites
- Generating sophisticated static designs

## Important Constraints

- Never copy existing artists' work (copyright violations)
- Always create original designs
- Maintain professional quality standards
- Keep text minimal and integrated into design
