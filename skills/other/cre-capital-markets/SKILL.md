# CRE Capital Markets Suite

You have access to 8 specialist capital markets skills for U.S. commercial real estate debt maturity, refinance, workout, recapitalization, and rescue-capital analysis.

## Available Skills

| Skill | File | Use When |
|---|---|---|
| Debt Maturity Diagnostic | `skills/debt-maturity-diagnostic.md` | User needs maturity risk, refinanceability, extension risk, or 30/60/90 day action plan |
| Refinance Proceeds Gap Analyzer | `skills/refinance-proceeds-gap-analyzer.md` | User needs supportable refinance proceeds, paydown gap, reserve need, or sensitivity |
| Extension / Workout Strategy Builder | `skills/extension-workout-strategy-builder.md` | User needs extension, modification, forbearance, discounted payoff, or lender give/get strategy |
| Rescue Capital Comparator | `skills/rescue-capital-comparator.md` | User needs preferred equity, mezzanine, JV equity, bridge, note purchase, or sale alternative comparison |
| Capital Stack Term Sheet Comparator | `skills/capital-stack-term-sheet-comparator.md` | User needs to normalize and rank competing debt, mezzanine, preferred equity, or JV term sheets |
| CMBS / Special Servicing Readiness Reviewer | `skills/cmbs-special-servicing-readiness-reviewer.md` | User needs CMBS watchlist, transfer, default, or special-servicing package readiness |
| Lender Update Package Builder | `skills/lender-update-package-builder.md` | User needs lender, servicer, or capital-provider update package and exhibit checklist |
| Recap IC Memo Writer | `skills/recap-ic-memo-writer.md` | User needs an IC memo for refinance, extension, workout, rescue capital, sale, or hold decision |

## How to Use

1. Read the user's request to determine which capital markets skill is needed.
2. Load the full skill file, for example: `Read skills/refinance-proceeds-gap-analyzer.md`.
3. Load relevant knowledge files when the skill asks for them.
4. Follow the Strategy steps exactly.
5. Produce output in the specified format.
6. Run Quality Checks before delivering results.

For deeper analysis, load knowledge bases:

- `knowledge/capital-markets-benchmarks.md` - debt sizing, refinance gap, DSCR, debt yield, LTV, and capital-stack screening
- `knowledge/workout-and-extension-structures.md` - extensions, modifications, forbearance, discounted payoff, deed-in-lieu, and lender give/get logic
- `knowledge/rescue-capital-and-pref-equity.md` - preferred equity, mezzanine debt, JV equity, bridge debt, note purchase, and rescue-capital comparison
- `knowledge/cmbs-servicing-and-default-playbook.md` - CMBS parties, transfer triggers, special-servicer package readiness, and borrower strategy
- `knowledge/underwriting-calc.md` - canonical CRE formulas
- `knowledge/risk-scoring.md` - risk categorization for IC memo synthesis

If the user says "$ARGUMENTS", use that to determine which skill to load.

## Quick Reference

**Debt Maturity Diagnostic** - Maturity urgency, loan snapshot, refinance tests, controlling constraint, action plan.

**Refinance Proceeds Gap Analyzer** - All-in payoff, supportable proceeds, total funding gap, sources, sensitivities.

**Extension / Workout Strategy Builder** - Structure comparison, lender protections, milestones, fallback path.

**Rescue Capital Comparator** - Preferred equity, mezzanine, JV equity, bridge, note purchase, DPO, sale alternatives.

**Capital Stack Term Sheet Comparator** - Net proceeds, all-in cost, recourse, reserves, control rights, scorecard.

**CMBS / Special Servicing Readiness Reviewer** - Servicing map, transfer/default risk, borrower package readiness.

**Lender Update Package Builder** - Lender-facing executive summary, NOI bridge, exhibit checklist, lender protections.

**Recap IC Memo Writer** - Decision memo for refinance, extension, workout, rescue capital, sale, or hold.
