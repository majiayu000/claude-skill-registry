# Frontend CSS

This Skill provides Claude Code with specific guidance on how to adhere to coding standards as they relate to frontend CSS styling.

## When to use this skill

Use this skill when:

1. Styling tables that display stock data, prices, and performance metrics
2. Creating color schemes for financial data with green/red indicators (gains/losses)
3. Building responsive layouts for portfolio dashboards and stock screeners
4. Styling charts and visualizations for technical analysis displays
5. Designing form styles for stock search and portfolio management inputs
6. Creating card components for individual stock information displays
7. Implementing dark/light mode themes for market data viewing
8. Styling error and success states for portfolio operations and transactions
