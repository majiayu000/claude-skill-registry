# Frontend Accessibility

This Skill provides Claude Code with specific guidance on how to adhere to coding standards as they relate to frontend accessibility.

## When to use this skill

Use this skill when:

1. Documenting API endpoints with clear, accessible formatting for tool consumption
2. Building a future web UI for portfolio management with keyboard navigation support
3. Creating CLI outputs with proper contrast and text hierarchies
4. Designing API documentation for stock data with proper semantic structure
5. Ensuring error messages are clear and actionable for end users
6. Building future interactive dashboards with proper ARIA labels and roles
7. Creating visualizations of stock performance with accessible color schemes
8. Implementing form inputs for portfolio and stock selection with proper labeling
