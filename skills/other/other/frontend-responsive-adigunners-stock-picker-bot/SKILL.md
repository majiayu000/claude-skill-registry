# Frontend Responsive

This Skill provides Claude Code with specific guidance on how to adhere to coding standards as they relate to responsive frontend design.

## When to use this skill

Use this skill when:

1. Building responsive layouts for stock quote and price information displays
2. Creating mobile-friendly portfolio management interfaces
3. Designing breakpoints for stock chart visualizations on different screen sizes
4. Implementing responsive tables that collapse or scroll on small screens
5. Creating touch-friendly buttons and controls for mobile stock trading operations
6. Designing flexible grid layouts for dashboard panels with market data
7. Ensuring stock data remains readable on all device sizes
8. Building responsive navigation for portfolio features and analysis tools
