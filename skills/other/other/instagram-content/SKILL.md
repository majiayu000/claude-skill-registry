# Instagram Content Skill

## Overview

This skill covers Instagram caption writing, visual brief creation, hashtag research strategy, Reels optimization, and platform-specific engagement tactics for 2024–2025 algorithm.

## Instagram Algorithm Key Factors (2025)

- **Reels** get 2–3x more reach than static posts
- **Carousels** drive highest saves and shares among feed formats
- **Comments** > reactions for ranking signals
- **Saves** are the strongest positive signal (bookmark = high value content)
- **Consistency** of posting cadence matters more than frequency
- **Story interactions** (polls, questions, sliders) boost overall profile reach
- **Hashtags** are secondary to content quality; 5–10 targeted > 30 generic

## Caption Structure Framework

### The AIDA Caption
```
[Attention: Bold first line — what stops the scroll]

[Interest: Context or story that makes them want more]

[Desire: The value/outcome/transformation]

[Action: Clear, single CTA]

.
.
.
#hashtag1 #hashtag2 #hashtag3
```

### The Micro-Story Caption
```
[Scene setter: 1 sentence, present tense]

[What happened / the tension]

[The turning point]

[The lesson or takeaway]

[Question to invite comments]

[Hashtags]
```

### The Educational Caption
```
[Hook: surprising fact or bold claim]

[Number] things about [topic]:

↳ [Point 1]
↳ [Point 2]
↳ [Point 3]

Save this post 🔖

[Hashtags]
```

## Reels Optimization

### Hook (First 1–3 seconds)
- Must stop the scroll immediately
- Options: surprising statement, fast cut, motion, text overlay with bold claim
- Avoid slow pans or fade-ins in the first second

### Structure (15–30 sec optimal)
```
0–3s:  Hook / attention grab
3–8s:  Setup / context
8–20s: Core content / value delivery
20–25s: Recap / takeaway
25–30s: CTA
```

### Caption for Reels
- First line: repeat or complement the hook (many users read before watching)
- Keep it short (100–150 words max for Reels)
- End with: "Save + share if useful" or "Comment [word] for [resource]"

## Hashtag Strategy

### Selection Logic
1. **Niche hashtags** (10K–100K posts): highest discoverability ratio
2. **Mid-tier hashtags** (100K–500K posts): balance reach vs. competition
3. **Broad hashtags** (1M+ posts): minimal ROI unless trending

### Recommended Sets by Content Type

**Educational/Informational**:
```
#[niche-specific] #[industry] #[topic] #[audience-type] #imparaconme
```

**Behind the Scenes / Storytelling**:
```
#[brandname] #[location] #[lifestyle] #[values] #storyofmybrand
```

**Product/Service Showcase**:
```
#[product-category] #[material/style] #[location-based] #[benefit]
```

**Rule of thumb**: 5–10 focused hashtags > 30 generic ones

## Workflow

### Step 1 — Content Type Selection
Based on the media asset (image/video/no media yet), select:
- Static image → Photo caption
- Multiple images → Carousel caption
- Video clip → Reels caption + brief
- No asset yet → Produce visual brief first

### Step 2 — Hook Drafting
Write 3 alternative first lines. Choose the one with:
- Highest curiosity gap
- Most specific/concrete language
- Strongest benefit or tension

### Step 3 — Caption Drafting
Follow the appropriate structure. Keep sentences short. Use line breaks after every 2–3 lines for readability.

### Step 4 — Hashtag Research
Load hashtag_research skill for platform-specific, audience-relevant hashtag sets.

### Step 5 — CTA Selection
Choose ONE CTA type:
- **Save-oriented**: "Save for later" (for educational content)
- **Comment-oriented**: "Tell me in the comments" / "Comment [X] to get [Y]"
- **Share-oriented**: "Share with a friend who needs this"
- **Profile-visit**: "Link in bio for [resource]"
