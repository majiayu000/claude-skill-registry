# 日本語社内文書・コミュニケーション作成スキル

## 概要

日本の企業で日常的に使われる社内文書やコミュニケーション文書を生成するスキルです。稟議書、社内通知、回覧文書から、朝礼スピーチ、人事異動挨拶、年始年末挨拶、社内報記事まで、幅広い社内コミュニケーションに対応します。

## 対応する文書の種類

| 文書種類 | 用途 | 形式 |
|---------|------|------|
| 稟議書 | 予算・購入・契約等の承認申請 | フォーマル文書 |
| 社内通知 | 制度変更・メンテナンス等の周知 | フォーマル文書 |
| 回覧 | 部署内での情報共有・確認 | 準フォーマル文書 |
| 朝礼スピーチ | 朝礼での3分スピーチ | 口語体 |
| 異動挨拶 | 着任・離任・退職時の挨拶 | フォーマル/準フォーマル |
| 年始・年末挨拶 | 新年・年末の社内挨拶 | フォーマル |
| 社内報記事 | 社内報・社内ニュースレター | 読みやすい文体 |

## 稟議書

### 基本構成

```
稟議書
───────────────────────────────────
文書番号: 稟-【YYYY】-【連番】
起案日:   YYYY年MM月DD日
起案部署: 【部署名】
起案者:   【氏名】

■ 件名
【稟議の件名】

■ 稟議内容
1. 目的
   【この稟議で何を実現するか】

2. 背景・経緯
   【なぜこの申請が必要か】

3. 具体的な内容
   【何を・いつ・どのように行うか】

4. 期待される効果
   【定量的・定性的な効果】

■ 費用
金額:     ¥【金額】（税込/税抜）
予算科目: 【科目名】
支出時期: YYYY年MM月〜YYYY年MM月

■ 承認欄
┌────┬────┬────┬────┐
│社長│部長│課長│起案者│
├────┼────┼────┼────┤
│    │    │    │    │
│    │    │    │    │
└────┴────┴────┴────┘

■ 添付書類
1. 【添付資料名1】
2. 【添付資料名2】
───────────────────────────────────
```

### 稟議書作成のルール
- **結論を先に**: 件名と目的で何を承認してほしいかを明確にする
- **金額は具体的に**: 見積書を添付し、税込/税抜を明記する
- **代替案を検討**: 比較検討した結果を記載すると説得力が増す
- **期限を明示**: 承認が必要な期日を明記する

参照: [examples/ringi.md](examples/ringi.md)

## 社内通知

### 基本構成

```
社内通知
───────────────────────────────────
通知番号: 通-【YYYY】-【連番】
発行日:   YYYY年MM月DD日

宛先: 【全社員 / 〇〇部門 各位】

発信者: 【部署名】
        【役職】 【氏名】

件名: 【通知の件名】について

本文:
【通知内容を簡潔に記載】

以上
───────────────────────────────────
```

### 社内通知の種類と注意点

| 種類 | ポイント |
|------|---------|
| 制度変更通知 | 変更前後の対比を明確に記載する |
| システムメンテナンス通知 | 日時・影響範囲・代替手段を必ず記載する |
| 人事異動通知 | 発令日・異動先・後任を明記する |
| 安全・防災通知 | 具体的な行動指示を含める |
| イベント通知 | 日時・場所・参加方法・締切を記載する |

参照: [examples/shanai-tsuchi.md](examples/shanai-tsuchi.md)

## 朝礼スピーチ

### 構成（3分スピーチの目安: 約800〜900文字）

```
1. 挨拶（おはようございます）
2. テーマの提示（今日は〇〇についてお話しします）
3. 本題（エピソード・気づき・学び）
4. 業務との関連（仕事にどう活かせるか）
5. 締めの言葉（今日も一日よろしくお願いいたします）
```

### スピーチのテーマ例
- 季節の話題（時候・行事）
- 最近のニュース・トレンド
- 業務で学んだこと・気づき
- お客様からのフィードバック
- 健康管理・安全意識
- チームワーク・コミュニケーション

### スピーチ作成のルール
- 「です・ます」調で統一する
- 専門用語を避け、誰にでも伝わる表現を使う
- 具体的なエピソードを1つ入れる
- ポジティブな結びにする

## 異動挨拶

### 着任挨拶
- 自己紹介（名前・経歴・趣味など）
- 異動先への意気込み
- 指導・協力のお願い

### 離任挨拶
- 在任期間への感謝
- 思い出深いエピソード
- 後任者への引き継ぎ言及
- 今後の活躍を祈る言葉

### 退職挨拶
- 在職期間への感謝
- お世話になった方々への謝辞
- 今後の予定（差し支えない範囲で）
- 末筆ながらの健勝・発展を祈る言葉

参照: [examples/jinji-aisatsu.md](examples/jinji-aisatsu.md)

## 年始・年末挨拶

### 年始挨拶（社内向け）
```
新年あけましておめでとうございます。
旧年中は大変お世話になりました。

【昨年の振り返りと今年の抱負を簡潔に】

本年もどうぞよろしくお願いいたします。
```

### 年末挨拶（社内向け）
```
今年も残すところあとわずかとなりました。
本年中は格別のご協力をいただき、誠にありがとうございました。

【今年の成果や感謝の言葉を簡潔に】

来年もよろしくお願いいたします。
よいお年をお迎えください。
```

## 社内報記事

### 記事の種類
- 部署紹介・新メンバー紹介
- プロジェクト報告・成果発表
- 社内イベントレポート
- 社員インタビュー
- 業界動向・ナレッジ共有

### 記事の基本構成
```
【見出し】（読者の関心を引くタイトル）

【リード文】（100文字程度で記事の要点を伝える）

【本文】
- 背景・経緯
- 具体的な内容・エピソード
- 関係者のコメント（可能であれば）
- まとめ・今後の展望

【写真・図表のキャプション指示】
```

### 社内報記事の文体
- 「です・ます」調を基本とする
- 堅すぎず、砕けすぎない親しみやすい文体
- 専門用語には補足説明を入れる
- 500〜1,500文字程度を目安とする

## 共通フォーマットルール

### 文書番号の付与
- 稟議書: `稟-YYYY-NNN`
- 社内通知: `通-YYYY-NNN`
- 回覧: `回-YYYY-NNN`
- 社内報: `報-YYYY-NNN`

### 日付の表記
- 正式文書: `令和〇年〇月〇日` または `YYYY年MM月DD日`
- 略式: `YYYY/MM/DD`

### 宛先の書き方
- 全社: `全社員 各位`
- 部門: `〇〇部 各位`
- 個人: `〇〇部 〇〇課 〇〇 様`
- 役職宛: `〇〇部長`（役職名に「様」は付けない）

## 生成時の確認事項

文書を生成する前に、以下をユーザーに確認してください：

1. **文書の種類**: 稟議書 / 社内通知 / 回覧 / 朝礼スピーチ / 異動挨拶 / 年始年末挨拶 / 社内報
2. **宛先**: 全社 / 特定部門 / 個人
3. **発信者**: 部署名・役職・氏名
4. **内容**: 文書の主旨・伝えたいこと
5. **トーン**: フォーマル度合い（公式文書 > 部内通知 > カジュアル）
6. **期限・日付**: 関連する日付情報
7. **承認欄**: 必要かどうか（稟議書の場合は承認者の役職リスト）

不明な項目はプレースホルダー `【〇〇】` で表示してください。
