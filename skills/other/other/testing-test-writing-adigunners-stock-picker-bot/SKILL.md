# Testing Test Writing

This Skill provides Claude Code with specific guidance on how to adhere to coding standards as they relate to testing in the stock_picker_bot project.

## When to use this skill

Use this skill when:

1. Writing unit tests for FastAPI endpoints with TestClient
2. Testing SQLAlchemy model definitions and database operations
3. Writing fixtures for test databases and sample stock data
4. Testing data validation with Pydantic models
5. Testing pandas/numpy data processing for stock analysis
6. Writing integration tests for yfinance data fetching
7. Testing error handling and exception scenarios
8. Writing tests for LLM API integrations and mocking external API calls
