## 웹 검색 도구

DuckDuckGo를 사용하여 최신 정보를 실시간으로 검색합니다. API 키가 필요 없습니다.

### 사용 가능한 도구

- **web_search**: 자연어 검색 쿼리로 웹 검색

### 사용법

- 최신 뉴스, 현재 이벤트, 제품 정보, 사실 확인이 필요할 때 반드시 사용하세요.
- 학습 데이터에 없는 최신 정보는 추측하지 말고 항상 검색 후 답변하세요.
- 검색어는 한국어 또는 영어 모두 사용 가능합니다.
