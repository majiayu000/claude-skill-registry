# 信源分级、内容防污染与电商风险核验体系

仅在需要检索、核验价格/评论/评测/直播/售后或处理高风险商品时读取。

---

## 一、 信源可信度四级金字塔与采信规则

网络上的导购信息、评测博客与问答社区充斥着大量商单、返利外链与水军软文。智能体在检索取证时，必须严格执行**信源可信度四级分级体系**，严禁将低信度营销内容作为决定性证据：

```
                    ┌───────────────────────────────────────────────┐
                    │  L1 级：法定资质与权威硬数据 (最高信度/绝对基准) │
                    │  - 国家/行业标准 (GB/T, QB/T, YY)、3C 认证编号  │
                    │  - 药监局批文、质检抽检公告、官方白皮书铭牌参数 │
                    └───────────────────────┬───────────────────────┘
                                            │
                    ┌───────────────────────┴───────────────────────┐
                    │  L2 级：高质量独立拆解与实测 (高信度/方法透明) │
                    │  - 自购样机、有完整测试环境/仪器/原始测量数据   │
                    │  - 明确指出产品故障案例、做工妥协与核心短板     │
                    └───────────────────────┬───────────────────────┘
                                            │
                    ┌───────────────────────┴───────────────────────┐
                    │  L3 级：真实多方客诉与使用反馈 (中信度/交叉佐证)│
                    │  - 维权投诉平台、垂直论坛长周期(3~12月)使用追评 │
                    │  - 仅用于发现潜在暗病线索，需 3 起以上同类归因  │
                    └───────────────────────┬───────────────────────┘
                                            │
                    ┌───────────────────────┴───────────────────────┐
                    │  L4 级：高风险商业推广与水军矩阵 (低信度/严格过滤)│
                    │  - 知乎/百度知道/贴吧/小红书导购软文、返利榜单  │
                    │  - 仅用于发掘市场在售候选 SKU，严禁支撑推荐排名 │
                    └───────────────────────────────────────────────┘
```

| 证据等级 | 代表性信源形态 | 采信与处理准则 |
|---|---|---|
| **L1 级（法定与官方硬数据）** | 国家标准全文（GB/T 等）、认监委 3C 认证库、国家药监局注册备案（国妆特字/医疗器械）、质检总局抽检公告、官方技术白皮书。 | **核心判据**。用于判定合规门槛、安全限量、基础物理规格与是否涉及批次召回。 |
| **L2 级（专业独立拆解/实测）** | 具备自购说明、标准化测试环境、高精度仪器原始数据、高清内部拆机图，并明确呈现测试失败案例与做工妥协的第三方深度评测。 | **推荐支撑**。用于核验内部真实用料、散热做工、电路保护与持续工况性能。 |
| **L3 级（长周期真实使用反馈）** | 垂直技术论坛长帖、黑猫投诉维权归因、电商平台 3~12 个月追评、维修师傅拆修记录。 | **风险预警**。用于排查装配公差、虚焊、断轴、密封圈老化、异味等高频暗病（须 3 起以上相同失效方可定性为通病）。 |
| **L4 级（商业软广与泛社交社区）** | 知乎/贴吧/百度知道/小红书中的“好物清单”、“神仙好物”、“闭眼入”、Top10 返利榜单、无测试步骤的纯开箱晒图。 | **严格过滤**。此级内容 90% 以上带有分销佣金（Affiliate）或商业合作属性，**仅可作为市场在售型号的发现线索，绝对禁止直接采信其排名或结论**。 |

## 二、 社区软广、导购博客与伪 UGC 识别过滤清单

在检索知乎、百度知道、百度贴吧、小红书及各类导购博客时，一旦命中以下特征，自动判定为高风险商业软广并降级处理：

### 1. 文本与句式特征（软广高频套路）
- **虚构第一人称痛点**：以“最近很多朋友/粉丝问我...”、“给闺蜜/爸妈挑了半天最后选了...”开篇，后文无任何测试数据直接给出产品链接。
- **极端情绪化与绝对化修饰**：频繁出现“闭眼入”、“天花板”、“同价位无敌”、“按头安利”、“后悔没早买”等缺乏实证支撑的形容词。
- **无痛痒“伪缺点”掩护**：评测文章假装客观列出缺点，但全是“包装盒太大”、“颜色太好看挑花眼”、“功能太多要看说明书”等无关痛痒的假缺点，刻意回避核心发热、噪音、材质缩水与售后翻车问题。

### 2. 商业利益链与排版特征（佣金与站群标志）
- **分销返利参数外链**：文章所有购买跳转链接均携带推广佣金参数（如 `?tag=`, `?aff=`, `&ref=`, `cps` 联盟代码）。
- **品牌矩阵与全家桶垄断**：在通用需求推荐中，不同价格档位推荐的全部是同一母公司旗下的子品牌或同一代工厂贴牌产品。
- **问答社区自问自答与控评**：知乎/贴吧中提问与回答发布时间高度接近，回答下方的评论区清一色跟帖夸赞且无真实使用质疑。

## 三、 电商平台（淘宝/京东/拼多多/抖音等）数据脱水指南

### 1. 评价区数据清洗
- **好评返现与刷单过滤**：短期内密集出现的 5 星好评，晒图构图/背景高度相似、文案句式重复度高者一律剔除。
- **变体与旧款评价迁移**：警惕商家将老款爆款链接的数万条好评直接迁移替换为新款减配产品。核对评价中的具体型号规格与当前在售 SKU 是否一致。
- **直击中差评聚类**：直接提取中差评与追加评价中的关键词，区分“物流包装破损”（非核心问题）与“开机异响/发热漏水/用料缩水/售后拒保”（核心质量缺陷）。

### 2. 促销价格脱水与真实底价核实
- **固定比较基准**：比对价格前必须固定具体 SKU、时间、库存、平台会员券、支付优惠与大件安装费。
- **政府补贴（国补/以旧换新）专项核查**：
  - 核实商品近 30~90 天的历史未补贴成交价，防范商家“先涨价后打折”套取补贴；
  - 提示用户部分国补订单锁定个人发票抬头不可修改，以及退货时补贴额度是否实时退还。
- **全生命周期总拥有成本 (TCO)**：必须综合核算专用耗材（滤芯/胶囊/刷头）后续单价、定期更换频次、保外维修成本及二手折旧。

## 四、 购后后悔抑制、决策可逆性与二手残值流转 (Regret Mitigation)

为有效降低用户的决策后悔概率，在给出选购建议时必须同步评估：
1. **决策可逆性（Reversibility Score）**：
   - 区分“七日无理由”与质量问题。核实拆封或通电后是否支持无理由退货、是否包含运费险；
   - 大件商品（床垫、电视、洗衣机、跑步机）核算打木架、搬运上楼费及退货产生的高额物流成本。
2. **闲置吃灰风险与二手残值（Liquidity Index）**：
   - 评估高闲置品类（如原汁机、半自动咖啡机、面包机、家用跑步机）的真实使用打理门槛；
   - 评估闲置 3~6 个月在二手流转平台（闲鱼/转转）的残值折价率（保值率高 vs 骨折难出手）。
3. **退换修与备件透明度**：
   - 优先选择售后网点普及、核心备件价格公开透明且交易留在正规可申诉平台内的方案。
